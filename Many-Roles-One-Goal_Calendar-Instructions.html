How to Add a Session to Your Calendar

Click "+ Add to calendar" on the agenda page first — that downloads a small file. Then find your setup below to finish adding it.

Windows + Outlook

Desktop app
1

Click "+ Add to calendar." The file saves to your Downloads folder — you may not see anything pop up, and that's okay.

2

Open File Explorer → click Downloads on the left → find the file you just downloaded.

3

Double-click the file. Outlook should open with the event ready to go.

4

Click Save & Close. Done — it's on your calendar!

Windows + Google Calendar

In your web browser
1

Click "+ Add to calendar." The file saves to your Downloads folder.

2

Go to calendar.google.com. Click the gear icon ⚙️ (top right) → Settings.

3

On the left, click Import & export → then Select file from your computer.

4

Choose the downloaded file, pick which calendar to add it to, then click Import.

Mac + Outlook

Desktop app
1

Click "+ Add to calendar." The file saves to your Downloads folder.

2

Open Finder → click Downloads on the left → find the file you just downloaded.

3

Double-click the file. Outlook should open with the event ready to go.

4

Click Save & Close. Done — it's on your calendar!

Mac + Google Calendar

In your web browser
1

Click "+ Add to calendar." The file saves to your Downloads folder.

2

Go to calendar.google.com. Click the gear icon ⚙️ (top right) → Settings.

3

On the left, click Import & export → then Select file from your computer.

4

Choose the downloaded file, pick which calendar to add it to, then click Import.

If a box pops up asking "How do you want to open this file?" Choose Outlook (or your calendar app) from the list, check the box that says "Always use this app," then click OK. After that, every session file will open the right way automatically.
